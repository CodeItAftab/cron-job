# Cron Job - Server Pinger

This project is designed to periodically ping your web servers to prevent them from entering a state of inactivity.

## Features
- Sends periodic pings to specified web servers.
- Ensures servers remain active and responsive.

## Usage
1. Clone the repository:
    ```bash
    git clone <repository-url>
    ```
2. Configure the list of servers to ping in the configuration file.
3. Set up the cron job to run the script at desired intervals.
